# User Preferences - Istana Laundry Management System

Preferensi pengguna untuk gaya pengkodean dan interaksi.

## Bahasa Interaksi
- Bahasa Indonesia (sesuai instruksi Rule 1a).

## Desain & Estetika
- Penggunaan skema warna yang premium dan dinamis.
- Brand color: Oranye (#FF6600).
- Desain modern dan responsif menggunakan Tailwind CSS v4.

## Struktur Kode
- Menggunakan arsitektur 3-layer (Presentation, Business Logic, Data Layer).
- Repository Pattern, Service Layer Pattern, dan Observer Pattern.
- Laravel 13 + PHP 8.4+.
